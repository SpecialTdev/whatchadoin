# Left Sidebar

좌측 사이드바는 Work 탭에서 **위젯 목록**을, Report 탭에서 업무일 목록을 표시한다.
이 문서는 위젯 시스템의 스펙을 다룬다. (Report 목록 등 일반 UI는 [UI.md](UI.md) 참고.)

구현: `src/components/WidgetList.tsx` · 모델·영속: `src/lib/widgets.ts` · 스타일: `src/app-view/App.css` · Rust 커맨드: `src-tauri/src/lib.rs`

## 위젯 목록 (Work 탭)

Work 탭 본문에 세로 스크롤 가능한 위젯 목록을 띄운다. 각 위젯은 `{ id, type, title }`.

### 동작 스펙

- **추가**: 목록 하단의 `+ Add widget` 버튼을 누르면 위쪽으로 위젯 카탈로그가 펼쳐지고, 한 종류를 고르면 목록 끝에 추가된다.
- **삭제**: 각 위젯 **우측 상단의 작은 빨간 원**이 remove 버튼. 즉시 제거(확인 없음). 이 버튼에서 시작한 포인터는 드래그로 잡히지 않는다.
- **순서 변경**: 위젯 **상단 바(헤더)가 드래그 핸들**. 위아래 정렬만 가능하며, **사이드바 밖으로는 옮길 수 없다**.
- **영속성**: 위젯 목록/순서는 File IO로 저장된다.

### 순서 변경 가이드 선 스펙 (커서 기준)

드래그 중 파란 삽입 가이드 선의 위치는 오직 커서로 결정한다.

- **R1 — Y만**: 가로 위치는 무시, 커서의 세로 위치만 본다.
- **R2 — 인덱스 규칙**: 커서보다 midpoint가 아래인 첫 위젯 *앞*에 삽입. 모든 위젯 midpoint보다 아래면 맨 끝.
- **R3 — 선은 하나, 경계에**: 대상 위젯 위(앞) 또는 마지막 위젯 아래(끝)에 한 줄만. **항목 사이 빈 공간(gap)에 커서가 있어도 끊기지 않고** 연속으로 따라온다.
- **R4 — 제자리면 선 없음**: 결과 위치가 원래 자리와 같으면 선을 숨기고, 놓아도 변화 없음.
- **R5 — 사이드바 이탈 금지**: 커서가 목록 영역을 벗어나면 선을 숨기고, 놓으면 취소(제자리).
- **R6 — 보이는 대로 드롭**: 놓는 순간 표시된 경계 위치로 정확히 이동.

> 배경: 초기 구현은 `elementFromPoint`로 위젯을 찾아, 항목 사이 gap에서 선이 사라지고 엉뚱한 위치로 튀었다. 위 스펙은 항목들의 rect midpoint를 직접 스캔해 이를 해결한다.

## 위젯 카탈로그

추가 가능한 위젯 종류는 `WIDGET_CATALOG`(`src/lib/widgets.ts`)에 정의한다. 본문은 `renderBody(widget)`(`WidgetList.tsx`)가 `type`별로 그린다.

| type              | label    | 설명                                  |
| ----------------- | -------- | ------------------------------------- |
| `basic-timer`     | 타이머   | 단순 카운트다운 타이머.               |
| `posture-check`   | 척추요정 | 설정 간격마다 자세 교정 알림(반복).   |
| `ppomodoro-timer` | 뽀모도로 | 집중/휴식 반복 + 자동 모드 전환.      |

### 새 위젯 추가 절차

1. `WidgetType`에 새 type 추가 + `WIDGET_CATALOG`에 `{ type, label }` 등록 (`src/lib/widgets.ts`).
2. `renderBody`에 해당 `case` 추가 (`src/components/WidgetList.tsx`).
3. 필요 시 `.widget-item[data-widget-type="..."]`로 스타일 추가 (`src/app-view/App.css`).
4. 아래 "위젯별 스펙"에 동작·데이터 스펙을 적는다.

### 타이머 (`basic-timer`)

- **용도**: 단순 타이머.
- **데이터/설정**: 사용자는 사용할 시간의 입력이 가능하며, 가장 최근 사용된 시간을 저장.
- **구성**: hh:mm:ss 및 progress bar indicator. start / pause, reset 으로 동작하는 2개의 버튼. 
- **비고**: 타이머 완료될 경우 system notification이 존재함. 뷰가 사라져도 타이머는 유지됨.

### 척추요정 (`posture-check`)

- **용도**: 설정된 시간마다 알림을 보냄.
- **데이터/설정**: 사용자는 5분 ~ 1시간 간격으로 alert 간격을 조정 가능. 현재 설정 시간이 저장됨. 
- **구성**: alert 간격을 조절하는 슬라이더 및 왼쪽에서 오른쪽으로 차오르는 progress bar indicator. start / pause 로 동작하는 버튼 1개. 썸네일.
- **비고**: 타이머 완료될 경우 타이머가 재시작되며, system notification이 존재함. 뷰가 사라져도 타이머는 유지됨.
슬라이더는 5분 ~ 10분까지 1분 간격, 10~60분 까지 5분 간격으로 존재.
타이머 조절될 경우 현재 진행시간을 유지하되, 진행 시간 > interval 일 경우 타이머 리셋.

### 뽀모도로 타이머 (`ppomodoro-timer`)

- **용도**: 뽀모도로 타이머 - X분 집중, Y분 휴식
- **데이터/설정**: 집중시간 설정, 휴식시간 설정 가능. 휴식모드 / 업무 모드 설정
- **구성**: mm:ss 입력/인디케이터, start / pause, reset 으로 동작하는 2개의 버튼. 휴식모드 / 업무 모드 토글.
- **비고**: basic timer와 유사하게 동작하지만, 반시계방향으로 remaining time이 줄어드는 red/black background indicator가 있어야 함. 타이머가 완료되면 알람과 함께 자동으로 반대 모드로 넘어가서 시작.

## AppView

### Work tab:
![alt text](docs/res/image-work.png)

#### Workspace 섹션 (Note + Kanban)
todo는 자유형 markdown note(WYSIWYG markdown 에디터)로 작성하고, 같은 내용을 칸반 보드로도 변환해 편집한다.
- **동시 표시**: 뷰를 토글로 골라 보는 대신 Note(상단)와 Kanban(하단)을 한 화면에 같이 띄운다. 두 패널 사이 구분선을 드래그해 높이 비율을 조절한다.
- **단일 소스 + 실시간 동기화**: note(markdown)가 원본이다. `## 제목` → 칸반 컬럼, `- [ ] / - [x]` 항목 → 카드(체크박스 = 완료 상태). 한쪽을 편집하면 다른 쪽이 즉시 반영된다.
- **포커스 모델**: 패널을 클릭하거나 툴바의 Note/Kanban 토글로 활성 패널을 정한다. 활성 패널만 편집 가능하며, 비활성 패널은 아웃포커스(흐림) 처리되고 인터랙션이 비활성화된다.
- **카드 이동**: 칸반 카드는 맨 왼쪽의 드래그 핸들로 잡아 컬럼 간 이동 및 컬럼 내 정렬을 한다(드롭 위치 미리보기 표시). 카드 텍스트는 핸들이 아닌 영역에서 자유롭게 편집한다.

### Report tab:
![alt text](docs/res/image-report.png)

left 사이드바에 work / report를 선택할 수 있도록.
 - work 선택 시 placeholder / report 선택 시 하루 단위의 report 목록 조회 가능.
 - report 목록 = 실제 events가 있는 업무일(최신순, 하루 경계 새벽 5시 기준). 선택 시 그날 리포트를 표출한다.
   - **집중 타임라인(Gantt)**: task별 집중 구간 막대(체크인 기반). 막대 사이 빈 구간 = 추적 공백(집중 분절).
   - **노트 활동 트랙**: 노트 변경(추가/완료/삭제)을 색 틱으로 표시. **Insights**: 활동 구간·이벤트 수·체크인 등 요약(계산형).
right 사이드바 event list는 추적된 실제 이벤트(노트 변경·체크인)를 발생 즉시 live로 표출한다. (메신저/게시판 접속 등 foreground 앱 이벤트는 phase 2/3.)

## 체크인 팝업 (Check-in)
주기적으로 "지금 뭐 하고 있어?" 팝업이 떠서 현재 작업을 빠르게 기록한다.
- **후보 목록 = 실제 todo**: 팝업의 작업 선택지는 mock이 아니라 Work note에서 추출한 실제 미완료 todo 항목이다.
- **새 작업 편입**: 목록에 없는 작업을 입력해 제출하면 note의 '진행 중' 컬럼에 카드로 추가된다.
- **직접 입력**: '직접 입력' 버튼을 누르면 체크인 대신 메인 창의 Work view가 앞으로 나오며 활성화되어(노트 에디터 포커스) 바로 작성할 수 있다.

# Styling Guide
레이아웃을 짤 때 margin이나 gap은 절대 쓰지 말고, <div> 대신 시맨틱 태그 위주로 사용한다.
요소 간의 구분은 오직 1px의 얇은 선(border, divide)과 내부 padding으로만 처리해서 선형적이고 에스테틱한 느낌을 강조한다.
대신 구분 요소간 배경색에 컬러를 주입해 구분감을 준다.
